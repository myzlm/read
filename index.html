声音设置

自定义语音引擎 接入本地 / 第三方 TTS，用上洛天依等声音模型

引擎需返回音频（wav / mp3）。测试会朗读示例句子。
💡 想用「洛天依」的声音？看这里
  1. 方案 A · 本地声音模型（最推荐）：部署开源的 GPT-SoVITS 或 Bert-VITS2，加载社区训练好的洛天依声音模型，然后按下方示例填入接口地址即可。
  2. 方案 B · 在线合成 API：任何支持自定义音色 / 声音模型 ID、返回音频的 HTTP 语音合成服务，都可以直接填入上面使用。
  3. 方案 C · 系统语音：如果安装了第三方系统语音引擎，在上方「搜索声音」里输入"洛天依"或"天依"看看有没有。

常见接口示例（GPT-SoVITS api_v2）：
http://127.0.0.1:9880/tts?text={text}&text_lang=zh&ref_audio_path=参考音频.wav&prompt_text=&prompt_lang=zh&speed_factor={rate}&media_type=wav&streaming_mode=false

Bert-VITS2 示例：
http://127.0.0.1:7860/voice?text={text}&language=zh&model_id=0&length_scale={pitch换算}

说明：引擎需允许跨域（CORS），本地部署的服务一般默认允许或可配置。
